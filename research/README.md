# Research records

The `*-candidates.json` files preserve discovery notes from primary-source research. Their status text can describe an intermediate verification state. They are not the final published inventory.

The reviewed inventory is [`docs/.vitepress/data/jobs.json`](../docs/.vitepress/data/jobs.json). It contains 26 selected NY/NJ postings, each with an exact title, employer, location, level rationale, duties, requirements, source URL, check date, and Chrome verification note. The downloadable copy in `docs/public/jobs.json` must match it. The published [source ledger](../docs/job-sources.md) records limitations and exclusions.

Research was checked on November 5, 2026. Chrome displayed descriptions and Apply controls for 23 selected postings. Three CoreWeave descriptions were reviewed in Chrome through the official employer ATS JSON, while the custom public job template did not render the job. Application forms for those three were not verified.

The earlier Atlas review is pinned to the source commit in `existing-research-review.md` and also published as `docs/existing-research.md`. The original repository was inspected read-only.
